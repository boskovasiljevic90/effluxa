# Effluxa brand exports

The Effluxa wordmark remains the existing product identity: `Eff` in navy or white, with `luxa` in blue. The mark is the existing app icon, exported as a standalone SVG for product and social use.

## Logo files

- `effluxa-wordmark.svg` / `.png` — transparent wordmark for dark backgrounds
- `effluxa-wordmark-light.svg` / `.png` — transparent wordmark for light backgrounds
- `effluxa-mark.svg` / `.png` — existing app mark for dark product surfaces
- `effluxa-mark-light.svg` / `.png` — mark variant for light surfaces
