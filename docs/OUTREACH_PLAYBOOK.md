# Effluxa partner outreach playbook

These messages are starting points. Personalise the first two sentences with a public observation about the firm. Do not mass-send identical copy, claim guaranteed savings or attach confidential client information.

## Pilot invitation

The lowest-risk pilot is one real file with sensitive fields redacted where possible. We agree in advance what the partner wants to learn, review the report together, and label findings as supported, unclear or not supported. Only verified outcomes are recorded as recovered value.

## Discovery questions

Ask these before showing features:

- Which client files are currently reviewed for leakage or unusual spend?
- What makes that review slow or difficult to repeat?
- Who validates a possible finding before it reaches the client?
- Would a source-linked review signal be useful in an existing monthly or quarterly conversation?
- Which file type would be safest for a first pilot?
- What would make the pilot worth repeating or paying for?

## Objection handling

### “We already use accounting software.”

That is compatible with the workflow. Effluxa is not a replacement for bookkeeping, reconciliation or tax work; it is a file-first screening and follow-up layer for a review conversation.

### “We cannot promise savings to clients.”

Neither should Effluxa. Findings are review signals with evidence and confidence. A value is treated as recovered only after a person verifies the outcome.

### “We do not want another integration.”

The first pilot does not require an integration. It starts with an export or document the client already has.

### “AI results are not trustworthy.”

The workflow is designed for review, not blind action. The partner sees the source context, calculation basis and confidence, and decides whether a finding is worth discussing.

## Do not say

- “Effluxa guarantees savings.”
- “Effluxa automatically detects fraud.”
- “The report is correct without human review.”
- “Every audit finishes in 30 seconds.”
- “Your client will recover €X.”

Use the measured processing time for the actual file type and route instead of making a universal speed claim.
