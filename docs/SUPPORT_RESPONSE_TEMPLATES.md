# Effluxa Support Response Templates

Use these templates from `support@effluxa.com`. Replace bracketed fields before sending. Keep replies short, factual and helpful.

## 1. First response

Subject: We received your Effluxa request

Hi [Name],

Thanks for contacting Effluxa. I’ve received your request about [topic] and will review it with the account details you provided.

If the issue is related to billing or checkout, please reply with the Effluxa account email and Paddle transaction/subscription reference if visible. Please do not send card numbers or passwords.

Best,  
Effluxa Support  
support@effluxa.com

## 2. Upload failed

Subject: Help with your Effluxa upload

Hi [Name],

Please confirm the file type (PDF, CSV, XLSX or XLS), approximate file size and the exact message shown by Effluxa. Do not send sensitive financial documents by email unless we specifically request a safe redacted example.

I’ll check whether this is a validation, account-limit or processing issue and come back with the next step.

Best,  
Effluxa Support

## 3. Report is limited or incomplete

Subject: About your Effluxa report

Hi [Name],

This report was generated from limited or isolated data, so it should be treated as a screening result rather than a complete view of the business. Effluxa can still highlight useful review points, but savings, vendor and risk conclusions may be incomplete.

If you want broader analysis, upload a wider statement, export or invoice set that covers the relevant period.

Best,  
Effluxa Support

## 4. Checkout failed

Subject: Help with your Effluxa checkout

Hi [Name],

I’m sorry the checkout did not complete. Please try the checkout again from the Effluxa dashboard and make sure the browser allows the Paddle checkout window to load. Do not send card details by email.

If it still fails, reply with the account email, selected plan and any Paddle transaction reference shown in the URL or checkout screen. I’ll check the transaction status and webhook record.

Best,  
Effluxa Support

## 5. Payment completed but access is missing

Subject: We’re checking your Effluxa access

Hi [Name],

Thanks for letting us know. Paddle can complete a payment before the Effluxa dashboard refreshes. Please sign out and back in once, then check the dashboard again.

If access is still missing, reply with the account email and Paddle transaction/subscription reference. We’ll verify the payment and restore the correct access state if the transaction is confirmed.

Best,  
Effluxa Support

## 6. Manage Billing

Subject: Manage your Effluxa subscription

Hi [Name],

You can manage payment details, invoices and subscription actions from Effluxa Dashboard → Settings → Manage Subscription. This opens Paddle’s customer portal.

If the button is unavailable, the account may not yet have a Paddle-linked subscription or may contain a legacy billing record. Reply with the account email and we’ll check it.

Best,  
Effluxa Support

## 7. Cancellation request

Subject: Effluxa cancellation

Hi [Name],

You can cancel Pro or Agency from Dashboard → Settings → Manage Subscription. Cancellation stops future renewals and access normally remains available through the current paid period.

If you cannot access the portal, reply from the account email and we’ll help verify the subscription.

Best,  
Effluxa Support

## 8. Refund request

Subject: We’re reviewing your Effluxa refund request

Hi [Name],

I’ve recorded your refund request for [product/transaction]. Refunds are reviewed against the transaction status, service delivery and applicable consumer rules. I’ll confirm the outcome after checking the Paddle record.

Please do not send card details. The Paddle transaction reference and account email are sufficient.

Best,  
Effluxa Support

Best,

## 10. Privacy/data deletion request

Subject: Your Effluxa data request

Hi [Name],

We can help with this request. Please reply from the account email and specify whether you want to delete one report, a client record or the complete account. Do not send passwords, card numbers or unnecessary financial documents.

We’ll verify ownership, check any active subscription and confirm the deletion scope before completing the request.

Best,  
Effluxa Support

## 11. AI report quality concern

Subject: We’re reviewing your Effluxa report

Hi [Name],

Thanks for flagging this. Effluxa reports are AI-generated informational analysis and can contain errors or incomplete interpretations. Please tell us which section appears incorrect and what source file type was uploaded.

We’ll review the report and use the case to improve the product. Important financial decisions should be verified with your accountant or qualified financial professional.

Best,  
Effluxa Support
